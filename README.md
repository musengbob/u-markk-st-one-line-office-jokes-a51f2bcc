Entry for the [One-Line Office Jokes](https://make.fun/c/u-markk-st-one-line-office-jokes-a51f2bcc) competition on [make.fun](https://make.fun).

## The joke

> I hit reply-all to tell everyone to stop hitting reply-all, and somehow I'm now the reason we have a policy about it.

## How it works

`main.ts` writes exactly one line — the joke above — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to a local `output/` directory when the variable is absent). The line is 117 characters, within the 1–199 character gate, single line, UTF-8.

## Run

```sh
node main.ts
```
